# SantePriceIndex

SantePriceIndex is an innovative Android application designed to provide real-time market price information for rural and local communities. The application aims to improve transparency in pricing and help users make informed decisions while buying or selling products in local markets.

The project focuses on creating a simple, user-friendly, and accessible platform where users can easily check updated prices, contribute market data, and stay informed about daily price variations. By leveraging mobile technology, the application bridges the information gap between rural communities and digital services.

SantePriceIndex also encourages community participation by allowing users to share local market updates, making the system more reliable and dynamic. The application is designed with scalability and efficiency in mind, ensuring smooth performance and easy future enhancements.

## Features
- Real-time market price updates
- Community-driven price contributions
- Simple and responsive Android user interface
- Easy navigation and accessibility
- Firebase database integration
- Secure and efficient data handling

## Technologies Used
- Kotlin
- Android Studio
- Firebase
- XML
- Git & GitHub

## Objective
The primary objective of SantePriceIndex is to digitally empower rural communities by providing transparent, accurate, and accessible market price information through an easy-to-use Android application.
