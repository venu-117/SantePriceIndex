# SantePriceIndex

SantePriceIndex is an Android application developed to provide real-time market price information and improve accessibility for rural communities through a simple and user-friendly platform.

## Features
- Real-time price updates
- Community-driven data collection
- Easy-to-use Android interface
- Rural market support system

## Technologies Used
- Kotlin
- Android Studio
- Firebase
- XML

## Objective
The main objective of this project is to help users access transparent and updated market price information digitally and efficiently.
